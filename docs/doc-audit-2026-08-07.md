# Doc audit — 2026-08-07

*Second full audit (the first is [doc-audit-2026-08-02.md](doc-audit-2026-08-02.md)).
68 living documents checked against the implementation; every claim below
was verified by grepping code, config, or the registry, not by reading
another document. Dated records — WORKLOG, devnotes, code reviews, plan
docs, research memos — were deliberately excluded: they describe what was
true when written and must not be retrofitted.*

## Why now

Three workstreams landed in eight days (observation-day filing, digest
section 9, the F-021 evidence-push repair) and the prose lagged all
three. CLAUDE.md §13 is explicit that in a public repository, prose which
overclaims what the code does is itself a defect. Two of the findings
were live on fapd.info.

## Governance gap

**#4 — GUIDE documented neither digest §9 nor the `PRESACT` collection.**
The append-only numbering rule named Recorded Votes first and Bill
Actions second, with no third; the §3 collection table had no `PRESACT`
row; and the 2026-08-02 status note listed only the govinfo collections
plus VOTES and BILLACTIONS, silently omitting `AGENCYPR` as well.

The whole section-9 workstream shipped 2026-08-06 without a GUIDE
amendment, and CLAUDE.md §2 requires GUIDE changes to *precede*
implementation. Ratified 2026-08-07 on the operator's instruction: §2
names Presidential Actions as the third append-only section, §3 gains a
Presidential actions subsection in the same shape as Recorded votes and
Bill actions, and the status note now admits both non-govinfo running
collections.

The process lesson is the one worth keeping: the code shipped, the tests
passed, the digest rendered, and nothing anywhere failed — because no
gate checks that a new section has a governing rule behind it.

## Judgment call: dated notes in a generated file

**#13** — `SOURCES.md` repeats "the agency class holds 500 requests a
day" across ~15 planned-source notes. These are dated probe records that
the registry keeps forever as accountability data, but they read
present-tense on a public page and the figure is now 3,000.

Resolved by adding a header note rather than rewriting fifteen records:
the Notes column is a dated log, budget figures are quoted as of the
probe, and the reader is pointed at `config.py` for the figure in force.
**A probe record edited to match today stops being evidence.**
