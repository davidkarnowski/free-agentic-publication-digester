## FOR THE OPERATOR — GUIDE.md drift (constitution; your call, not ours)

1. **§3 dating rule vs index sources.** §3 says an undated item "falls
   back to the observed date — the only honest option," unconditionally.
   `HtmlIndexAdapter` deliberately DROPS undated index entries (the
   most-defended dating behavior in the codebase, reasoned in CLAUDE.md
   §9 and adding-sources.md) — the carve-out exists everywhere except
   the constitution. Suggested: a §3 sentence distinguishing feeds
   (bounded by the publisher → observation fallback) from indexes
   (unbounded archives → drop and log).
2. **§6 r14 describes half the retry ceiling.** "Per run" is the exact
   wording that permitted the 39.7M-token day; the per-ITEM durable
   ceiling (`summary_attempts`, `MAX_ITEM_SUMMARY_ATTEMPTS`) that
   actually stops the ladder is unwritten.
3. **§5's two-artifact model has moved.** /today now performs
   mechanical editorial work (the §3 backfill split, the fedcal
   weekend/holiday judgment, the prose gate on openings) — all
   zero-LLM and defensible, but `fedcal.py` is a reader-facing
   editorial surface with no GUIDE basis at all.
4. **§7 manifest-chain claim** ("deletion or reordering detectable from
   the files alone") overclaims — same limits now stated in
   PROVENANCE.md; the constitution's threat-model row rests on it.
5. **§4 backpressure** ("its collector doubles its interval") is
   enforced for one class of three; the govinfo class — the one that
   exhausted its budget on 2026-07-30 — has no backpressure override
   (it has the 15% reserve instead).
6. **§6 r8's trigger has arrived.** "Measure first, then cap" was
   waiting for real baselines; the ledger now holds three incidents'
   worth. Setting the cap is ops-backlog OB-4 / review R1.
7. **§3 collections table** reads as an inventory but is the 2026-07
   plan (five synced; CHRG/CRPT/DCPD unstarted; VOTES/BILLACTIONS live
   outside the table).
8. **r13's window arithmetic** admits three-to-four days where the rule
   says two — a code fix (review D14), listed here because the
   constitution's wording is what the fix must match.

## Method note

Three parallel auditors (site-facing / governance / ops+agents), all
claims verified against HEAD with file:line evidence, load-bearing
symbol references spot-checked by execution where possible. The audit
found the paper roughly 55% accurate — and found that the docs written
WITH drift tests (SOURCES.md, docs/agents/ ownership matrix, the dev
stack README) were the accurate ones. The lesson is the same one the
code review §II.1 taught: what can drift, will; what is pinned, holds.
