# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment, no personal
attacks. The project itself is strictly non-partisan — political
advocacy in issues, pull requests, or discussions is off-topic here the
same way it is off-limits in the digest.

Enforcement contact: **hustleyourcity@gmail.com**. Reports are handled
by the maintainer and kept confidential.
